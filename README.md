# PLORANA

Store-orientierte Expo/React-Native-Codebasis.

## Ziel
Eine native iOS-/Android-App für geführte Selbstreflexion ohne KI-Auswertung.
Die inhaltlichen Antworten der Nutzer:innen bleiben im MVP lokal auf dem Gerät.

## Enthalten
- Expo SDK 57
- React Native
- iOS- und Android-Kennung
- EAS-Konfiguration für Development, Preview und Production
- vollständiger erster PLORANA-Reflexionsweg in App.js

## Vor Store-Release noch erforderlich
- finales App-Icon und Splash/Brand Assets
- Datenschutzerklärung und Support-URL
- Apple Developer / App Store Connect
- Google Play Console
- finale Bundle-/Package-ID vor dem ersten Store-Upload prüfen
- Geräte- und Accessibility-Tests
